Ablation Experiment Description:
1. Benchmark: Fold5 of the original model, full model
2. A1_NoCfC: Remove the PreprocessCfC module to validate the importance of CfC for extracting dynamic information from sequence features
Scientific hypothesis: The CfC module is critical for extracting dynamic information from sequence features; removing it will significantly reduce performance
3. B1_NoLTC: Completely remove LTC temporal processing, keep only graph convolution
Scientific hypothesis: Validate the importance of LTC temporal modeling for protein interaction prediction
4. C1_NoLTCDense: Keep the LTC layer but remove the original temporal Dense (LTC Dense) layer, replace with the basic fully connected layer SimpleDense
Scientific hypothesis: Validate the necessity and contribution of temporal-aware Dense (LTC Dense) compared to a standard fully connected layer
5. D1_NoComp: Keep CfC+LTC but remove all compensation mechanisms (structural enhancement, multi-scale, Set2Set pooling, residual connections, LTC Dense) to test the limits of basic temporal components
Scientific hypothesis: Validate the performance limit of CfC+LTC temporal components when all compensation mechanisms are removed
6. E1_AB_NoCfC_NoLTC: Remove both CfC preprocessing and LTC temporal processing
Scientific hypothesis: Validate the impact of temporal modeling component combinations on overall performance and test model degradation
